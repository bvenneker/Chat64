# ZX Spectrum ROM, OpenSe Basic 3.2.1 (seBasic321)

This project uses **OpenSE BASIC 3.2.1 (seBasic321)** as the basis for its ZX Spectrum ROM.

## Original project

The original OpenSE BASIC project is an open-source replacement/alternative ROM for the Sinclair ZX Spectrum, providing an enhanced version of the Spectrum BASIC environment.

This project is **based on OpenSE BASIC 3.2.1** and retains the original work of the OpenSE BASIC authors.

Please refer to the original OpenSE BASIC project for information about the original software, its authors, licensing, and history.

## Modifications

The ROM used in this project has been modified from the original seBasic321 source to meet the requirements of this project.

The modifications are documented directly in the accompanying assembly source file. Please see the comments in the ASM file for details of the changes made to the original OpenSE BASIC code.

The modifications may include changes required for compatibility with the hardware and software used by this project.
